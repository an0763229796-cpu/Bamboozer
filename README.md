## Vercel Speed Insights

Start collecting performance metrics, follow these steps.

### 1. Install our package

Start by installing `@vercel/speed-insights` in your existing project.

```bash
npm i @vercel/speed-insights
```

### 2. Add the Next.js component

Import and use the `<SpeedInsights />` Next.js component into your app's layout or your main file.

```tsx
import { SpeedInsights } from "@vercel/speed-insights/next"
```

For full examples and further reference, please refer to our documentation:
https://vercel.com/docs/speed-insights/quickstart?framework=nextjs#add-the-speedinsights-component-to-your-app

### 3. Deploy & Visit your Site

Deploy your changes and visit the deployment to collect your first events.

If you don't see data after 30 seconds, check for content blockers and try to navigate between pages on your site.

Or, install automatically with Vercel Agent (free).

Automatically generate a pull request with Speed Insights configured for your project — at no charge.
